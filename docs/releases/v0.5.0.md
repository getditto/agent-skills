## Agent Skills v0.5.0

This release packages all seven Ditto skills for direct installation through
the Ditto CLI. Developers can install the skills into supported agents without
publishing a separate package to each agent's marketplace.

The bundle includes DQL, data modeling, mesh networking, sync subscriptions,
Data Streams, and the Swift and Kotlin SDK skills. The complete skill list is
generated below from the release manifest.

### Release assets

- `ditto-skills.tar.gz`: the canonical `skills/` tree, `LICENSE.md`, and
  `skills-manifest.json` at the archive root.
- `skills-manifest.json`: each skill's name, path, and description.

Tests, contributor documentation, and plugin wrappers are excluded from the
archive. The `v0.5.0` tag versions this skills bundle; individual plugin versions
remain independent.

### Install with the Ditto CLI

These commands require the CLI changes in
[ditto-cli PR #6](https://github.com/getditto/ditto-cli/pull/6).
While this repository is private, set `GITHUB_TOKEN` or `DITTOSH_GITHUB_TOKEN`
to a token with access to `getditto/agent-skills`.

```bash
dittosh skills versions
dittosh skills add write-dql --ref v0.5.0 --agent claude
dittosh skills add --all --ref v0.5.0 --agent codex
dittosh skills add --all --ref v0.5.0 --agent antigravity
dittosh skills update --all --ref v0.5.0
```

Use `--project <existing-directory>` for a project-local installation.
The CLI PR supports Claude, Codex, OpenCode, Gemini, Antigravity, Cursor,
Copilot, and Windsurf targets; Cursor, Copilot, and Windsurf require project
scope. Antigravity installs use `~/.gemini/config/skills/` globally and
`.agents/skills/` within a project.

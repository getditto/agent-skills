## Agent Skills v0.6.1

This patch release fixes links to repository-only files in installed skills.
The bundle still contains the same thirteen skills as v0.6.0, and no skill
guidance changed.

### Fixed

- 27 links in ten skills pointed out of `skills/` with relative paths, such
  as `../../tests/js-sdk/README.md` and `../../docs/install-js.md`. Those files
  are not in the release archive or in an installed skill, so the links broke
  for agents. They now link to the files on GitHub, for example
  `https://github.com/getditto/agent-skills/blob/main/tests/js-sdk/README.md`.
  Affected skills: `js-sdk`, `js-node`, `js-web`, `js-react-native`,
  `js-expo`, `swift-sdk`, `kotlin-sdk`, `write-dql`, `data-modeling`, and
  `ditto-mesh-networking`.
- `scripts/validate-sdk-skills.py` now rejects a relative link that leaves
  `skills/`, and checks that GitHub links into this repository point to a path
  that exists. The Release workflow runs it before publishing.

Links between skills, such as `../js-sdk/assets/runtime.ts`, are unchanged.
They resolve when the linked skill is installed alongside, which
`dittosh skills add` does in dittosh 0.3.0 and later.

### Release assets

- `ditto-skills.tar.gz`: the canonical `skills/` tree, `LICENSE.md`, and
  `skills-manifest.json` at the archive root.
- `skills-manifest.json`: each skill's name, path, and description.

Tests, contributor documentation, and plugin wrappers are excluded from the
archive. The bundle version is independent of individual plugin versions.

### Install with the Ditto CLI

Update existing installations:

```bash
dittosh skills versions
dittosh skills update --all --ref v0.6.1
```

Use `--project <existing-directory>` to update a project-local installation.
To add skills you have not installed yet, use `dittosh skills add --all`.

## Agent Skills v0.6.1

This patch release makes installed skills self-contained. Skills no longer link
to test code or contributor docs that installed copies don't include; the code
they pointed to is now copied into the skill. The bundle still contains the same
thirteen skills as v0.6.0.

### Fixed

- Skills linked to files outside `skills/`, such as `../../tests/js-sdk/README.md`
  and the Kotlin harness projects. Installed skills don't include those files, so
  the links were broken for agents. Each link is now either local content or
  plain text:
  - `kotlin-sdk`: the minimal test skeleton in `references/testing.md` is copied
    from the JVM store test CI runs. It had drifted from that test. The new
    `references/reference-projects.md` has the tested JVM and Android Gradle
    build files, which `gradle-project-generation.md` tells agents to copy.
  - `js-web`: the new `references/browser-fixture.md` has the React browser app
    CI runs against WASM.
  - `js-sdk`, `js-node`, `js-react-native`, `js-expo`, and `write-dql`: links to
    test-harness reports are now plain text.
- Human-facing `README.md` files link to repository files on GitHub instead of
  with relative paths.

### For contributors

- `scripts/sync-snippets.py` copies marked regions of code from `tests/` into
  skill Markdown. CI and the Release workflow run it with `--check`, so a copy
  can't drift from the code CI runs.
- `scripts/validate-sdk-skills.py` rejects links that leave `skills/`, and links
  to this repository on GitHub outside a `README.md`.

See CONTRIBUTING.md, "Keep skills self-contained".

### Release assets

- `ditto-skills.tar.gz`: the canonical `skills/` tree, `LICENSE.md`, and
  `skills-manifest.json` at the archive root.
- `skills-manifest.json`: each skill's name, path, and description.

Tests, contributor documentation, and plugin wrappers are excluded from the
archive. The bundle version is independent of individual plugin versions.

### Install with the Ditto CLI

Update existing installations:

```bash
dittosh skills versions
dittosh skills update --all --ref v0.6.1
```

Use `--project <existing-directory>` to update a project-local installation.
To add skills you have not installed yet, use `dittosh skills add --all`.

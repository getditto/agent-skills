## Agent Skills v0.6.0

This release adds Ditto JavaScript and TypeScript guidance for Node.js,
browsers and React, React Native, and Expo. The bundle now contains thirteen
skills, including all seven skills from v0.5.0.

### What's new

- `js-sdk`: the shared JavaScript/TypeScript API guide, with reusable runtime,
  React provider and query-hook assets.
- `js-node`, `js-web`, `js-react-native`, and `js-expo`: platform-specific setup,
  lifecycle, deployment, and troubleshooting workflows.
- `native-app-config`: shared Apple and Android permissions, entitlements,
  and configuration guidance, also linked from the Swift SDK skill.
- An Expo task-app generator with local CRUD, observers, permission handling,
  and loading/error states. Its verified starter uses Ditto 5.2.0,
  Expo 57.0.31, React Native 0.86.3, and React 19.2.3.
- Scoped `ditto-js` plugin installation and portable packages that keep the
  six companion skills together.

JavaScript runtime and browser fixtures cover Ditto 5.0.3, 5.1.0, and 5.2.0.
Native build and emulator checks are documented separately from physical-radio
and background-execution coverage. Browser storage remains memory-only, and
Expo requires a development build rather than Expo Go. See the
[JavaScript installation guide](https://github.com/getditto/agent-skills/blob/v0.6.0/docs/install-js.md)
for setup and the supported framework boundaries.

### Release assets

- `ditto-skills.tar.gz`: the canonical `skills/` tree, `LICENSE.md`, and
  `skills-manifest.json` at the archive root.
- `skills-manifest.json`: each skill's name, path, and description.

Tests, contributor documentation, and plugin wrappers are excluded from the
archive. The bundle version is independent of individual plugin versions.

### Install with the Ditto CLI

Install all skills together to preserve the JavaScript family's sibling
references and the Expo generator's shared assets:

```bash
dittosh skills versions
dittosh skills add --all --ref v0.6.0 --agent codex
dittosh skills add --all --ref v0.6.0 --agent claude
dittosh skills update --all --ref v0.6.0
```

Use `--project <existing-directory>` for a project-local installation.
Updating existing installations does not add previously uninstalled skills;
use `skills add --all` to add the new JavaScript family.

# DQL Skill Test Harness — Node.js SDK, Multi-Version

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an automated test suite that runs every DQL example query documented in the public `ditto-dql` skill against actual Ditto Node SDK installations (`@dittolive/ditto@4.14.4` and `@dittolive/ditto@5.0.0`), reporting per-version pass/fail/expected-fail. This converts the skill from "internally consistent prose" into "verified-against-real-SDKs documentation."

**Architecture:**
- Tests live in `plugins/ditto-dql/tests/` (ships with the plugin).
- Queries are extracted from skill markdown via a Node script — no second source of truth.
- The runner spins up a Small Peer with the Node SDK, loads a pedagogical-schema test dataset (transformed once from the real `~/Developer/dql-metrics/benchmarks/skills-test/movies.ndjson`), and runs each query as `[preQueries], query, [postQueries]` with isolation via per-test markers.
- Per-query metadata (`availableIn`, expected row count, first-row spot check, preQueries, postQueries) lives in a `catalog.json` alongside the extracted queries.
- Multi-version testing uses two isolated `node_modules/` trees keyed by SDK version; the test runner is parametric over which SDK build it dlopens.
- A reporter classifies each result as PASS / FAIL / PASS-AS-EXPECTED (off-version failed correctly) / FAIL-UNEXPECTED.

**Tech Stack:** Node.js (ESM, no TypeScript to keep dependencies minimal), `@dittolive/ditto` (the official Ditto Node SDK) at two pinned versions, `gray-matter` or a tiny custom parser for YAML frontmatter, `node:test` runner for assertions, GitHub Actions for CI matrix.

## Decisions locked with the user

| Decision | Choice |
|---|---|
| Query source | Extract from public skill markdown (not reuse `benchmarks.json`) |
| Pass criteria | No error + row count + first-row spot check |
| Version gating | `availableIn` array per entry; PASS-AS-EXPECTED on off-version failures |
| Location | `plugins/ditto-dql/tests/` inside this plugin repo |

## Compatibility reference (locked findings driving expected results)

| Feature | 4.14.x | 5.0.x | Notes |
|---|---|---|---|
| Most SELECTs, comparison, BETWEEN, CASE, GROUP BY, HAVING, ORDER BY, LIMIT/OFFSET | ✓ | ✓ | |
| ANY/EVERY/SATISFIES, ARRAY/OBJECT FOR comprehensions, WITHIN | ✗ | ✓ | Parser error on 4.14.x |
| COUNTER (`APPLY ... INCREMENT BY`) | ✓ (4.13+) | ✓ | |
| PN_COUNTER (`APPLY ... PN_INCREMENT BY`) | ✓ (4.11+) | ✓ | |
| `DO UPDATE_LOCAL_DIFF` | ✓ (4.12+) | ✓ | |
| `#profile` directive / `PROFILE` keyword | ✗ | ✓ | |
| XOR operator | ✓ (v4 only) | ✗ | Removed in v5.0; returns v5.1 |
| `INSERT ... ON ID CONFLICT DO MERGE` | ✓ (alias for DO UPDATE) | ✗ | Removed in v5.0; returns v5.1 |
| `ADVISE` / `ADVISE AND PROVISION` | ✗ | ✗ | v5.1.0+ only |
| `USE IDS` on mutations | ✗ | ✗ | Parser TODO in both versions |
| Strict-mode default | strict (true) | lenient (false) | Affects object→CRDT inference on INSERT |

These drive the `availableIn` and expected-fail logic in the runner.

## Catalog schema (`tests/catalog/catalog.json`)

Single JSON file, array of entries. One entry per testable query found in the skill markdown.

```jsonc
[
  {
    "id": "sk_op_eq_basic",
    "source": {
      "file": "plugins/ditto-dql/skills/dql/references/operators.md",
      "line": 74,
      "heading": "## 3. Comparison operators"
    },
    "query": "SELECT title FROM movies WHERE rated = 'R' LIMIT 5",
    "preQueries": [],
    "postQueries": [],
    "availableIn": ["4.14.x", "5.0.x"],
    "expect": {
      "rowCount": 5,
      "firstRow": { "title": "Pulp Fiction" }   // OR "*" to match any row
    },
    "expectError": false,        // true for negative-example WRONG queries
    "tags": ["operator", "comparison"]
  },
  {
    "id": "sk_op_xor_v4_only",
    "source": { ... },
    "query": "SELECT title FROM movies WHERE is_classic XOR imdb.rating > 9",
    "availableIn": ["4.14.x"],
    "expect": { "rowCount": ">=1" },
    "expectError": false   // but PASS-AS-EXPECTED-FAIL on 5.0.x
  }
]
```

Off-version behavior is fully derivable from `availableIn`:
- If running 5.0.x and `availableIn` lacks `5.0.x` → expect either parse error or runtime error.
- If running 4.14.x and `availableIn` lacks `4.14.x` → expect parse error.

- The real `movies.ndjson` at `~/Developer/dql-metrics/benchmarks/skills-test/movies.ndjson` exists, is readable, and isn't going anywhere.

// runner/version-shim.mjs
import { createRequire } from "node:module";
import path from "node:path";

export async function loadSdk(version) {
  if (!["4.14.4", "5.0.0"].includes(version)) {
    throw new Error(`Unsupported DITTO_SDK_VERSION: ${version}. Supported: 4.14.4, 5.0.0`);

  const requireFromSdk = createRequire(path.join(sdkRoot, "package.json"));
  const sdkPath = requireFromSdk.resolve("@dittolive/ditto");
  return await import(sdkPath);
}

// scripts/transform-dataset.mjs
import fs from "node:fs";
import path from "node:path";
import os from "node:os";

const cfg = JSON.parse(fs.readFileSync(
  path.resolve(import.meta.dirname, "..", "catalog", "schema-mapping.json"),
  "utf8"
));

const src = cfg.from.replace(/^~/, os.homedir());
const dst = path.resolve(import.meta.dirname, "..", "fixtures", "movies-pedagogical.ndjson");
fs.mkdirSync(path.dirname(dst), { recursive: true });

const lines = fs.readFileSync(src, "utf8").split("\n").filter(Boolean).slice(0, cfg.limit);
const out = lines.map(raw => {
  const r = JSON.parse(raw);
  return JSON.stringify({
    _id: r._id?.id || r._id,
    title: r._id?.title || r.title,
    year: parseInt(r._id?.year || r.year, 10),
    runtime_minutes: r.runtime ?? null,
    genres: r.genres ?? [],
    director: { name: r.directors?.[0] ?? null, born: null },
    cast: (r.cast ?? []).map(name => ({ name, role: "" })),
    ratings: {
      imdb: r.imdb?.rating ?? null,
      rotten_tomatoes: r.tomatoes?.viewer?.meter ?? null,
      metacritic: null
    },
    box_office_millions: r.imdb?.votes ? Math.floor(r.imdb.votes / 10000) : null,
    tags: r.countries ?? [],
    watch_count: 0,
    is_classic: parseInt(r._id?.year || r.year, 10) < 1980,
    released: (r.released ?? "").slice(0, 10)
  });
}).join("\n");

fs.writeFileSync(dst, out + "\n");
console.log(`Wrote ${lines.length} docs to ${dst}`);
```

### Task 5: Markdown query extractor

**Files:**
- Create: `plugins/ditto-dql/tests/scripts/extract-queries.mjs`

Walks every `.md` file in `plugins/ditto-dql/skills/dql/`, pulls every ` ```sql ` code block, and emits a draft catalog entry per query.

- [ ] **Step 1: Write the extractor**

```javascript
// scripts/extract-queries.mjs
import fs from "node:fs";
import path from "node:path";
import crypto from "node:crypto";

const SKILL_ROOT = path.resolve(import.meta.dirname, "..", "..", "skills", "dql");
const OUT = path.resolve(import.meta.dirname, "..", "catalog", "catalog.json");
const IGNORE = path.resolve(import.meta.dirname, "..", "catalog", "ignore.json");

function walk(dir) {
  return fs.readdirSync(dir, { withFileTypes: true }).flatMap(e => {
    const p = path.join(dir, e.name);
    if (e.isDirectory()) return walk(p);
    if (e.isFile() && p.endsWith(".md")) return [p];
    return [];
  });
}

function extract(file) {
  const text = fs.readFileSync(file, "utf8");
  const lines = text.split("\n");
  const entries = [];
  let currentHeading = "";
  let nearbyAvailableIn = null;
  let inSqlBlock = false;
  let sqlBuf = [];
  let sqlStart = 0;

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i];

    if (/^#{1,6}\s/.test(line)) currentHeading = line.trim();
    const availMatch = line.match(/Available in:.*?(?:SDK\s+)?([\d.]+(?:\.x|\+)?)/i);
    if (availMatch) nearbyAvailableIn = availMatch[1];

    if (!inSqlBlock && /^```sql\s*$/.test(line)) {
      inSqlBlock = true; sqlBuf = []; sqlStart = i + 1; continue;
    }
    if (inSqlBlock && /^```\s*$/.test(line)) {
      inSqlBlock = false;
      const sql = sqlBuf.join("\n").trim();
      // Skip negative examples (search recent lines for "WRONG" / "❌")
      const recentContext = lines.slice(Math.max(0, sqlStart - 6), sqlStart).join("\n");
      const isWrong = /❌|WRONG|do not use|don't use/i.test(recentContext);
      // Skip parameter-only queries (no concrete substitution possible)
      const hasOnlyParams = sql.includes(":") && !sql.match(/=\s*[0-9'"]/);

      entries.push({
        id: hashId(file, sqlStart, sql),
        source: {
          file: path.relative(path.join(SKILL_ROOT, "..", "..", "..", ".."), file),
          line: sqlStart,
          heading: currentHeading
        },
        query: sql,
        availableIn: inferAvailableIn(nearbyAvailableIn),
        expectError: isWrong,
        _hints: { isWrong, hasOnlyParams }
      });
      continue;
    }
    if (inSqlBlock) sqlBuf.push(line);
  }
  return entries;
}

function hashId(file, line, sql) {
  const h = crypto.createHash("sha1").update(`${file}:${line}:${sql}`).digest("hex").slice(0, 8);
  const slug = path.basename(file, ".md").replace(/[^a-z0-9]/gi, "_");
  return `sk_${slug}_${h}`;
}

function inferAvailableIn(tag) {
  if (!tag) return ["4.14.x", "5.0.x"];
  if (/^5\.0/.test(tag)) return ["5.0.x"];
  if (/^4\./.test(tag))   return ["4.14.x", "5.0.x"];   // 4.x features generally work in 5.0 too unless explicitly removed
  if (/^4\.x/i.test(tag)) return ["4.14.x"];            // "v4.x only" markers
  return ["4.14.x", "5.0.x"];
}

const ignore = fs.existsSync(IGNORE) ? new Set(JSON.parse(fs.readFileSync(IGNORE, "utf8"))) : new Set();
const all = walk(SKILL_ROOT).flatMap(extract).filter(e => !ignore.has(e.id));
fs.writeFileSync(OUT, JSON.stringify(all, null, 2));
console.log(`Extracted ${all.length} queries → ${OUT}`);
console.log(`  Negative examples (expectError=true): ${all.filter(e => e.expectError).length}`);
console.log(`  Param-only (likely non-runnable):     ${all.filter(e => e._hints.hasOnlyParams).length}`);
```

```javascript
// runner/assertions.mjs

export function assertRowCount(actual, expected, id) {
  if (typeof expected === "number" && actual !== expected) {
    throw new Error(`[${id}] expected exactly ${expected} rows, got ${actual}`);
  }
  if (typeof expected === "string") {
    const m = expected.match(/^(>=|<=|>|<|=)\s*(\d+)$/);
    if (!m) throw new Error(`[${id}] invalid expect.rowCount: ${expected}`);
    const [, op, nStr] = m;
    const n = parseInt(nStr, 10);
    const cmp = { ">=": actual >= n, "<=": actual <= n, ">": actual > n, "<": actual < n, "=": actual === n }[op];
    if (!cmp) throw new Error(`[${id}] expected rowCount ${expected}, got ${actual}`);
  }
}

export function assertFirstRow(actual, expected, id) {
  if (!expected || expected === "*") return;
  if (!actual) throw new Error(`[${id}] expected first row matching ${JSON.stringify(expected)}, got no rows`);
  for (const [k, v] of Object.entries(expected)) {
    const actualV = k.split(".").reduce((o, p) => o?.[p], actual);
    if (actualV !== v) {
      throw new Error(`[${id}] expected first.${k} = ${JSON.stringify(v)}, got ${JSON.stringify(actualV)}`);
    }
  }
}
```

// runner/run.mjs
import fs from "node:fs";
import path from "node:path";
import os from "node:os";
import { loadSdk } from "./version-shim.mjs";
import { assertRowCount, assertFirstRow } from "./assertions.mjs";
import { seedMovies } from "../scripts/seed-store.mjs";

const VERSION = process.env.DITTO_SDK_VERSION;
if (!VERSION) { console.error("Set DITTO_SDK_VERSION=4.14.4|5.0.0"); process.exit(1); }
const LICENSE = process.env.DITTO_OFFLINE_LICENSE || process.env.DITTO_PLAYGROUND_TOKEN;
if (!LICENSE) { console.error("Set DITTO_OFFLINE_LICENSE or DITTO_PLAYGROUND_TOKEN"); process.exit(1); }

const catalog = JSON.parse(fs.readFileSync(
  path.resolve(import.meta.dirname, "..", "catalog", "catalog.json"),
  "utf8"
));

const sdk = await loadSdk(VERSION);
const ditto = new sdk.Ditto({ type: "onlinePlayground", appID: process.env.DITTO_APP_ID || "00000000-0000-0000-0000-000000000000", token: LICENSE });
const storeDir = fs.mkdtempSync(path.join(os.tmpdir(), "ditto-dql-test-"));
await ditto.start({ persistenceDirectory: storeDir });
const store = ditto.store;

console.log(`Seeding movies dataset against SDK ${VERSION}…`);
const seeded = await seedMovies(store);
console.log(`  seeded ${seeded} docs`);

const results = [];
for (const entry of catalog) {
  const result = { id: entry.id, version: VERSION, status: null, message: null };
  const inVersion = entry.availableIn.includes(VERSION.replace(/\.[0-9]+$/, ".x"));
  try {
    for (const q of entry.preQueries || []) await store.execute(q);
    const r = await store.execute(entry.query);
    const rows = r.items.map(i => i.value);
    if (entry.expectError) {
      result.status = "FAIL-UNEXPECTED-PASS";
      result.message = `Query expected to error but returned ${rows.length} rows`;
    } else if (!inVersion) {
      result.status = "PASS-UNEXPECTED-ON-VERSION";
      result.message = `Query is tagged unavailable on ${VERSION}, but it returned ${rows.length} rows`;
    } else {
      try {
        if (entry.expect?.rowCount !== undefined) assertRowCount(rows.length, entry.expect.rowCount, entry.id);
        if (entry.expect?.firstRow) assertFirstRow(rows[0], entry.expect.firstRow, entry.id);
        result.status = "PASS";
      } catch (e) {
        result.status = "FAIL-ASSERTION";
        result.message = e.message;
      }
    }
    for (const q of entry.postQueries || []) {
      try { await store.execute(q); } catch (e) { /* cleanup; ignore */ }
    }
  } catch (e) {
    if (!inVersion || entry.expectError) {
      result.status = "PASS-AS-EXPECTED-FAIL";
      result.message = String(e.message || e).slice(0, 200);
    } else {
      result.status = "FAIL";
      result.message = String(e.message || e).slice(0, 200);
    }
  }
  results.push(result);
}

await ditto.stop();
fs.rmSync(storeDir, { recursive: true, force: true });

const outPath = path.resolve(import.meta.dirname, "..", "results", `${VERSION}.json`);
fs.mkdirSync(path.dirname(outPath), { recursive: true });
fs.writeFileSync(outPath, JSON.stringify(results, null, 2));

const counts = results.reduce((a, r) => (a[r.status] = (a[r.status] || 0) + 1, a), {});
console.log(`\nResults for ${VERSION}:`, counts);
console.log(`Detail: ${outPath}`);

const failures = results.filter(r => r.status.startsWith("FAIL"));
process.exit(failures.length === 0 ? 0 : 1);
```

# ditto-mesh (Claude Code plugin wrapper)

This directory exists only to satisfy the Claude Code plugin/marketplace
layout — the skill content lives once, canonically, in the repo-root
[`skills/mesh-networking/`](../../skills/mesh-networking/) directory.

The wrapper symlinks **only the skills this plugin ships**, so installing
`ditto-mesh` gives you the mesh-networking skill and nothing else.

| Item | Where |
|---|---|
| Skill (mesh-networking) | [`skills/mesh-networking/SKILL.md`](skills/mesh-networking/SKILL.md) |
| Human-facing docs | [`skills/mesh-networking/README.md`](skills/mesh-networking/README.md) |

Do not add skill content here. See [`CONTRIBUTING.md`](../../CONTRIBUTING.md)
for how skills are packaged per tool.

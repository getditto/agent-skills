## What it does

The normative program: open, subscribe, observe, write, read back, close. One function,
`runMinimalApp`, does all of it and returns a transcript; `main.dart` runs it once and
shows the transcript. Both files are copies of the harness fixture that CI runs,
generated by the repository's snippet sync. It is offline: an offline license, every
peer-to-peer transport off, no server.

It is a demonstration, not an app structure: it closes Ditto when it is done. In an app
that keeps running, the instance lives in a service instead
([widget-integration.md](../references/widget-integration.md)).

## Program

`lib/minimal_app.dart`:

<!-- snippet: flutter-minimal-app -->
<!-- Generated by scripts/sync-snippets.py from code CI runs. Edit the marked source, not this block. -->
```dart
import 'dart:async';

import 'package:ditto_live/ditto_live.dart';
import 'package:flutter/foundation.dart';

/// Opens Ditto, observes a query, writes and reads back one document, then
/// closes everything. Returns the transcript; [onLine] sees each line as it
/// is produced.
///
/// With no [persistenceDirectory], Ditto uses the SDK's default persistence
/// directory, which is not deleted between launches (web: an in-memory
/// store).
Future<List<String>> runMinimalApp({
  required String license,
  String? persistenceDirectory,
  void Function(String line)? onLine,
}) async {
  final lines = <String>[];
  void emit(String line) {
    lines.add(line);
    onLine?.call(line);
  }

  // Required on 5.0.x, automatic from 5.1.0; memoized, so always safe.
  await Ditto.init();
  final ditto = await Ditto.open(
    DittoConfig(persistenceDirectory: persistenceDirectory),
  );
  SyncSubscription? subscription;
  StoreObserver? observer;
  StreamSubscription<QueryResult>? changes;
  try {
    ditto.setOfflineOnlyLicenseToken(license);

    // Offline demo: no peer-to-peer radios. Set each transport; on 5.0.x,
    // setAllPeerToPeerEnabled(false) leaves AWDL and Wi-Fi Aware on. Web has
    // none to turn off.
    if (!kIsWeb) {
      ditto.updateTransportConfig((config) {
        config.peerToPeer.bluetoothLE.isEnabled = false;
        config.peerToPeer.lan.isEnabled = false;
        config.peerToPeer.awdl.isEnabled = false;
        config.peerToPeer.wifiAware.isEnabled = false;
      });
    }
    ditto.sync.start();

    subscription = ditto.sync.registerSubscription('SELECT * FROM cars');
    final firstMatch = Completer<int>();
    // No onChange: listen to `changes` once, right away. An observer that
    // also has onChange keeps every result buffered in its unlistened
    // `changes` stream (5.0.0 through 5.2.0).
    observer = ditto.store.registerObserver(
      'SELECT * FROM cars WHERE color = :color',
      arguments: {'color': 'blue'},
    );
    changes = observer.changes.listen((result) {
      final count = result.items.length;
      if (count > 0 && !firstMatch.isCompleted) firstMatch.complete(count);
    });

    // A fixed _id with ON ID CONFLICT DO UPDATE keeps one car per launch.
    await ditto.store.execute(
      'INSERT INTO cars DOCUMENTS (:car) ON ID CONFLICT DO UPDATE',
      arguments: {
        'car': {'_id': 'blue-toyota', 'make': 'Toyota', 'color': 'blue'},
      },
    );
    final count = await firstMatch.future.timeout(const Duration(seconds: 10));
    emit('observer: $count car(s)');

    final result = await ditto.store.execute(
      'SELECT * FROM cars WHERE color = :color',
      arguments: {'color': 'blue'},
    );
    final cars = result.items.toList();
    emit('read-back make: ${cars.first.value['make']}');

    final version = RegExp(r'\d+\.\d+\.\d+').firstMatch(Ditto.version);
    emit('SDK version: ${version?.group(0)}');
    emit('platform: ${Ditto.currentPlatform.name}');
  } finally {
    // Cancel while Ditto is open: the stream listener, then the observer and
    // the subscription.
    await changes?.cancel();
    observer?.cancel();
    subscription?.cancel();
    await ditto.close();
  }
  emit('closed: ${ditto.isClosed}');
  return lines;
}
```

## main.dart

`lib/main.dart`, replacing the one `flutter create` wrote:

<!-- snippet: flutter-minimal-main -->
<!-- Generated by scripts/sync-snippets.py from code CI runs. Edit the marked source, not this block. -->
```dart
import 'dart:async';

import 'package:flutter/widgets.dart';

import 'minimal_app.dart';

const _license = String.fromEnvironment('DITTO_LICENSE');

void main() => runApp(const TranscriptApp());

/// Runs [runMinimalApp] once and renders its transcript.
class TranscriptApp extends StatefulWidget {
  const TranscriptApp({super.key});

  @override
  State<TranscriptApp> createState() => _TranscriptAppState();
}

class _TranscriptAppState extends State<TranscriptApp> {
  final _lines = <String>[];

  @override
  void initState() {
    super.initState();
    unawaited(
      runMinimalApp(license: _license, onLine: _add).catchError((Object error) {
        _add('error: $error');
        return _lines;
      }),
    );
  }

  void _add(String line) {
    // Also on stdout, so a build run from the command line shows it.
    debugPrint('transcript: $line');
    if (mounted) setState(() => _lines.add(line));
  }

  @override
  Widget build(BuildContext context) => Directionality(
    textDirection: TextDirection.ltr,
    child: ColoredBox(
      color: const Color(0xFFFFFFFF),
      child: Padding(
        padding: const EdgeInsets.all(24),
        child: Text(
          _lines.join('\n'),
          style: const TextStyle(color: Color(0xFF000000), fontSize: 16),
        ),
      ),
    ),
  );
}
```
<!-- /snippet -->

It imports `package:flutter/widgets.dart` only: `package:flutter/material.dart` is

## Running it

A new project, from nothing:

1. `flutter create --platforms=android,ios,macos,web minimal_app`, then
   `cd minimal_app` and `flutter pub add ditto_live`.
2. Add the two files above. Delete `test/widget_test.dart`: it tests the counter app
   `flutter create` wrote.
3. Apply the platform configuration in [setup.md](../references/setup.md): the Podfile
   platform line and simulator fix (iOS), the entitlements in both files and the
   Info.plist key (macOS), `minSdk` and the compileSdk override (Android), and the iOS
   Info.plist keys. Web needs none.
4. Write the license to a file outside the project, readable only by you
   (`chmod 600`): `{"DITTO_LICENSE": "<your offline license token>"}`.
5. `flutter run -d macos --dart-define-from-file=<that file>` (or `-d chrome`, or a
   device ID). The window shows the five transcript lines; the console prints them with
   a `transcript: ` prefix.

Without the define the license is empty and the transcript is one line,
`error: DittoException(<activation> The license failed verification. Obtain a valid
license token at https://portal.ditto.live.)` (executed, macOS release, 5.2.0). Why a
file and not `--dart-define`, and what it does not hide:
[testing.md](../references/testing.md#ditto-in-the-loop-integration_test). Delete
`build/` before sharing the project: compiled builds embed the license.

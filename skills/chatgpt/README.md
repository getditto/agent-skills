# Ditto v5 Migration — ChatGPT Custom GPT

This directory contains instructions to create a Custom GPT on ChatGPT that helps developers migrate Ditto SDK applications from v4.14 to v5.0.

## Files

- `system-prompt.md` — The complete system prompt / instructions to paste into your Custom GPT
- `instructions.md` — Step-by-step guide to create the Custom GPT

## Quick Setup

1. Go to [chat.openai.com](https://chat.openai.com) → **Explore GPTs** → **Create a GPT**
2. Switch to the **Configure** tab
3. Set **Name**: `Ditto v5 Migration Assistant`
4. Set **Description**: `Helps migrate Ditto SDK apps from v4.14 to v5.0 across Swift, Kotlin, C++, Rust, Flutter, JavaScript, .NET, and Go`
5. Paste the contents of `system-prompt.md` into the **Instructions** field
6. Save and share

See `instructions.md` for detailed setup steps.

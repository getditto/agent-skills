# Ditto v5 Migration — Gemini Gem

This directory contains instructions to create a Gemini Gem that helps developers migrate Ditto SDK applications from v4.14 to v5.0.

## Files

- `system-prompt.md` — The complete instructions to paste into your Gemini Gem
- `instructions.md` — Step-by-step guide to create the Gem

## Quick Setup

1. Go to [gemini.google.com](https://gemini.google.com) → **Gems** → **New Gem**
2. Set **Name**: `Ditto v5 Migration Assistant`
3. Paste the contents of `system-prompt.md` into the **Instructions** field
4. Click **Save**

See `instructions.md` for detailed setup steps.
